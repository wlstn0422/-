# 매일 경영·경제 케이스 노트

매일 아침 전날 나온 DART 공시와 경제신문 기사를 모아 공부용 노트를 자동으로 만들어 주는 프로그램입니다. 합병·분할·증자·IPO 같은 재무 사례부터 신사업 전략, 가격 인상, 마케팅 캠페인, 공급망, 노사, 공정거래, 관세, 금리·환율 같은 경영학·경제학 사례까지 폭넓게 모으고, 사례마다 분석에 필요한 이론(포터의 5 Forces, 신호이론, 가격탄력성, 게임이론, 통화정책 전달 경로 등)을 쉽게 풀어서 붙여 줍니다. 회계(K-IFRS)와 세무(법인세법·상증법) 관점도 함께 짚고, 업종 대표 기업을 하루 하나씩 골라 매출·이익·직원 수·평균 연봉과 업계 1위 대비 위치를 보여주기 때문에 숫자 감각을 기르는 데도 쓸 수 있습니다.

## 매일 받는 노트 구성

1. 오늘 한눈에: 공시 사례, 뉴스 사례, 오늘의 이론 수업, 오늘의 기업
2. 오늘의 공시 사례(3건): 공시 원문 핵심 항목, 회사 규모 대비 거래 크기, 공시에서 짚을 대목, 이론으로 읽기, 회계·세무로 읽기, 생각해볼 질문, 관련 기사
3. 뉴스로 보는 경영·경제 사례(3건): 재무·경영·경제 분야가 고르게 섞이도록 고른 기사마다 읽을 때 쓸 이론, 분석 순서, 기사에서 찾아볼 숫자
4. 오늘의 이론 수업: 그날 사례와 가장 관련 깊은 이론 하나를 쉬운 설명, 깊게 보기, 적용 순서, 실제 예, 자주 하는 오해까지 자세히 풀어 줍니다. 이론 39개를 한 바퀴 다 돌기 전에는 같은 이론이 다시 나오지 않아 평일 기준 8주면 39개를 모두 한 번씩 배웁니다. 그날 사례와 이어지는 이론부터 먼저 고르기 때문에 대부분의 수업은 그날 공시나 기사에 바로 대입해 볼 수 있습니다.
5. 오늘의 기업: 그 업종이 돈 버는 구조, 연도별 숫자, 규모 진단, 업종 안 순위, 듀퐁 분해, 현금흐름 생애주기, 유효세율, 돈 감각 환산, 예산 감각 연습문제
6. 공시 목록과 뉴스 브리핑: 공시는 유형별로, 기사는 18개 분야(M&A, 분할, IPO, 자본정책, 실적, 지배구조, 경쟁·공정거래, 인사·노동, 공급망, 무역·통상, 가격·소비, 마케팅, 스타트업, 글로벌 기업, ESG, 세제·정책, 전략·신사업, 거시경제)로 분류
7. 회계·세무 카드와 퀴즈

토요일에는 한 주의 사례와 이론을 모은 복습 노트가 나오고, 한 달에 한 번 업종별 규모 지도(대표 기업 100여 곳의 매출·이익·자산·직원·평균 연봉)가 갱신됩니다. 이론 39개는 [경영·경제 이론 사전](reports/theories.md) 한 페이지에도 모여 있어 교재처럼 찾아볼 수 있습니다.

| 분야 | 이론 카드 |
|---|---|
| 경영전략 | 5 Forces, 본원적 경쟁전략, 가치사슬, 자원기반관점(VRIO), 앤소프 성장전략, 수직계열화와 거래비용, 규모·범위의 경제와 학습곡선, 네트워크 효과와 플랫폼, 파괴적 혁신, BCG 매트릭스, M&A 시너지와 승자의 저주, 복합기업 할인 |
| 마케팅 | STP, 4P·7P, 브랜드 자산, 가격 전략과 가격차별, 고객 생애가치·획득비용, 혁신 확산과 캐즘 |
| 재무관리 | 기업가치 평가, 자본구조와 WACC, 정보 비대칭과 신호이론, 배당·자사주 정책, IPO 저평가, 영업레버리지, 대리인 이론 |
| 조직·인사, 생산·운영 | 조직구조, 보상과 동기부여, 구조조정·노사관계, 공급망과 채찍효과, 린 생산과 재고관리 |
| 경제학 | 가격탄력성, 시장구조, 게임이론, 외부효과와 ESG, 통화정책, 환율, 경기순환과 재정정책, 비교우위와 관세, 행동경제학 |

## 처음 설정(10분)

### 1. DART 인증키 발급(무료)

1. [opendart.fss.or.kr](https://opendart.fss.or.kr) 접속 후 상단 '인증키 신청/관리' → '인증키 신청'
2. 개인 용도로 신청하고 이메일 인증을 마치면 40자리 인증키가 나옵니다(하루 2만 건까지 무료, 이 프로그램은 하루 수백 건 정도 씁니다)

### 2. GitHub에 키 등록

저장소 Settings → Secrets and variables → Actions → New repository secret

| 이름 | 값 | 필수 |
|---|---|---|
| `DART_API_KEY` | 위에서 받은 인증키 | 필수 |
| `ANTHROPIC_API_KEY` | Claude API 키(공시·뉴스 사례 해설을 AI로 더 깊게 쓰고 싶을 때) | 선택 |

### 3. 첫 실행

Actions 탭 → '매일 케이스 노트' → Run workflow. 2~3분 뒤 `reports/README.md`에 첫 노트 링크가 생깁니다. 그다음부터는 평일 아침 6시 30분(한국시간)에 저절로 만들어집니다.

처음 한 번은 작업(task)에 `scale`을 넣어 실행하면 업종별 규모 지도가 바로 만들어집니다. 특정 기업을 깊게 보고 싶으면 작업에 `company`, 회사 이름에 `삼성전자`처럼 넣으면 됩니다.

### 4. 휴대폰으로 보기(선택)

- 가장 쉬운 방법: GitHub 앱에서 `reports/README.md`를 열면 마크다운이 그대로 보기 좋게 표시됩니다.
- 웹페이지로 보기: Settings → Pages → Source를 'Deploy from a branch', 폴더를 `/docs`로 지정하면 `https://<아이디>.github.io/<저장소>/`에서 볼 수 있습니다(비공개 저장소는 GitHub 유료 플랜이 필요합니다).

## 내 컴퓨터에서 실행

파이썬 3.11 이상이 필요합니다.

```bash
pip install -r requirements.txt

# Windows(PowerShell): $env:DART_API_KEY="발급받은키"
export DART_API_KEY=발급받은키

python -m casenote doctor            # 키와 인터넷 연결 점검
python -m casenote daily             # 오늘 노트
python -m casenote company 삼성전자   # 기업 하나 깊게 보기(이름 또는 종목코드)
python -m casenote scale             # 업종별 규모 지도
python -m casenote weekly            # 지난 7일 복습
python -m casenote daily --date 2026-11-20   # 특정 날짜로 다시 만들기
```

결과는 `reports/`(마크다운)와 `docs/`(웹페이지)에 저장됩니다. 키 없이 실행하면 뉴스 사례, 이론 수업, 회계·세무 카드, 퀴즈만 채워집니다.

## 매일 30분 공부 루틴(제안)

1. 오늘 한눈에(2분): 어제 무슨 일이 있었는지 훑기
2. 오늘의 이론 수업(8분): 쉬운 설명을 읽고, '사례에 적용하는 순서'를 소리 내어 따라가 보기
3. 사례 하나 깊게(10분): 공시 사례나 뉴스 사례 하나를 골라 원문을 열고, 오늘 배운 이론의 적용 순서대로 분석해 보기. 공시 사례라면 그 거래의 분개도 직접 써보기
4. 오늘의 기업 숫자 세 개 기억하기(5분): 매출, 영업이익률, 직원 1인당 매출
5. 퀴즈(5분)

토요일에는 복습 노트의 '주말 과제'처럼 사례 하나를 여섯 줄(무슨 일, 왜, 어떤 이론, 숫자, 회계·세금, 내가 담당자라면)로 정리해 두면 면접과 실무 보고서에 그대로 쓸 수 있습니다.

## 내 입맛에 맞게 바꾸기

| 파일 | 바꿀 수 있는 것 |
|---|---|
| `config.yaml` | 공시·뉴스 사례 수, 이론 수업 수와 반복 간격, 관심 기업(watchlist), 기사 수, AI 해설 사용 여부와 모델·노력 수준 |
| `data/knowledge/theories/` | 경영·경제 이론 카드. 분야별 파일에 새 카드를 추가하거나 설명을 보강하면 노트와 이론 사전에 바로 반영됩니다 |
| `data/knowledge/cards.yaml` | 회계·세무 카드와 퀴즈 |
| `data/news_sources.yaml` | 뉴스 분야, 분야별 키워드·이론·확인할 숫자, 구글 뉴스 검색어, 언론사 RSS 주소 |
| `data/industries.yaml` | 업종과 대표 기업 목록, 업종별 돈 버는 구조 설명과 관련 이론 |
| `data/benchmarks.yaml` | 규모 기준선, 세율, 예산·최저임금 같은 기준 숫자(해가 바뀌면 숫자만 고치면 됨) |

## 비용

- DART API: 무료
- GitHub Actions: 공개 저장소는 무료, 비공개 저장소는 월 2,000분 무료 한도 안에서 충분합니다(한 번에 2~5분)
- AI 해설(선택): Claude API 사용량만큼 과금됩니다. 공시·뉴스 사례 각 3건, 노력 수준 medium 기준으로 하루 수백 원 안팎입니다. 키를 등록하지 않으면 쓰지 않습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 노트에 'DART 사용 중단: 등록되지 않은 인증키' | Secrets의 `DART_API_KEY` 값에 공백이 섞였는지, 키가 맞는지 |
| '요청 제한 초과' | 하루 2만 건 한도. 같은 날 수동 실행을 여러 번 했는지 |
| 금융지주·보험사 숫자가 빈칸 | DART 재무 API가 금융업 일부를 다루지 않습니다 |
| 뉴스가 0건 | 언론사 RSS 주소가 바뀌었을 수 있습니다. `data/news_sources.yaml`에서 주소를 고치거나 빼면 됩니다 |
| 아침에 노트가 늦게 생김 | GitHub 예약 실행은 몰리는 시간에 수십 분 늦어질 수 있습니다 |

## 폴더 구조

```
casenote/            프로그램 코드
  dart.py            DART API(공시검색, 주요사항보고서, 재무제표, 직원 현황)
  events.py          공시 분류, 상세 항목 정리, 핵심 사례 고르기, 공시 유형별 이론 연결
  financials.py      재무 파싱, 비율, 유효세율, 현금흐름 생애주기
  sizing.py          규모 진단, 돈 감각 환산, 예산 연습문제
  news.py            RSS 수집, 중복 제거, 분류
  theory.py          이론 선택, 이론 수업 간격 관리, 뉴스 사례 고르기, 이론 퀴즈
  knowledge.py       회계·세무 카드 선택, 퀴즈
  report.py          노트 만들기(daily, company, scale, weekly, 이론 사전)
  ai.py              (선택) Claude 해설
  templates/         노트 서식
data/                이론·회계 카드, 기준표, 업종 목록, 뉴스 설정, 실행 기록
reports/             만들어진 노트(마크다운)
docs/                만들어진 노트(웹페이지)
tests/               테스트(가상의 회사 데이터 사용)
```

## 참고

공시 숫자는 DART 원문 기준이고, 해설과 이론·회계 카드는 공부용 요약입니다. 법령과 기준은 2026년 11월 기준으로 정리했으니 실무 문서에 인용할 때는 국가법령정보센터, 금융위원회·거래소 공지에서 원문을 다시 확인하세요. 투자 판단용 자료가 아닙니다.
