# 매일 경영·경제 케이스 노트

매일 아침 전날 나온 DART 공시와 경제신문 기사를 모아 공부용 노트를 자동으로 만들어 주는 프로그램입니다. 합병·분할·증자·IPO 같은 재무 사례부터 신사업 전략, 가격 인상, 마케팅, 공급망, 노사, 공정거래, 관세, 금리·환율, 그리고 회계 이슈, 세법 개정, 상법 개정, 나라 예산과 연금 같은 제도 사례까지 폭넓게 모읍니다. 사례마다 분석에 필요한 이론과 제도를 쉽게 풀어 붙이고, 평일마다 경영·경제 이론 수업 하나와 전공 수업(재무회계, 원가관리회계, 세법, 상법, 재정학) 하나를 자세히 다룹니다. 세법과 상법은 입법 취지, 만들 당시 배경, 바탕 이론, 경제적 효과, 실제 사례, 실제 효과까지 함께 보여줍니다. 업종 대표 기업을 하루 하나씩 골라 매출·이익·직원 수·평균 연봉과 업계 1위 대비 위치도 보여주기 때문에 숫자 감각을 기르는 데도 쓸 수 있습니다.

## 매일 받는 노트 구성

1. 오늘 한눈에: 공시 사례, 뉴스 사례, 이론 수업, 전공 수업, 오늘의 기업, 기사가 많았던 분야, 30분 읽는 순서
2. 오늘의 공시 사례(3건): 경영학·경제학 교과서의 사례 연구 문체(~이다, ~한다)로 씁니다.
    - 사례 개요: 사실관계, 거래의 성격(개념 정의와 지분율에 따른 회계 분류 등), 거래 규모(예: 회사 총자산의 약 6분의 1)
    - 이론 적용: 이론의 요지와 예시, 그리고 공시 수치를 이론에 그대로 넣은 분석 3~5개(기업가치 환산, 연 5% 가정의 투자 손익분기, 부채비율 변화, 지분 희석 규모 등)와 요약
    - 용어 해설: 그 사례에 처음 나온 전문용어의 정의(노트 안에서 한 번만)
    - 심화 학습(접혀 있음): 공시 원문 항목, 관련 이론, 회계·세무·법, 전공 카드, 생각해볼 질문, 관련 기사
3. 뉴스로 보는 경영·경제 사례(4건): 재무, 경영, 경제, 제도(회계·세법·상법·재정) 분야에서 하나씩 고릅니다. 기사 첫 문장으로 사실관계를 보여 주고, 제목 속 단서(예: 'MZ 겨냥', '세수 증가')를 찾아 이론을 적용한 분석, 용어의 의미, 주요 수치, 분석의 관점을 붙입니다. 이론 설명과 분석 순서는 '이론 심화'에 접혀 있습니다.
4. 오늘의 이론 수업: 그날 사례와 가장 관련 깊은 경영·경제 이론 하나를 쉬운 설명, 깊게 보기, 적용 순서, 실제 예, 자주 하는 오해까지 풀어 줍니다. 39개를 한 바퀴 다 돌기 전에는 같은 이론이 다시 나오지 않아 평일 기준 8주면 모두 한 번씩 배웁니다.
5. 오늘의 전공 수업: 월요일 재무회계, 화요일 원가관리회계, 수요일 세법, 목요일 상법, 금요일 재정학. 그날 공시와 기사에 이어지는 주제를 먼저 고르고, 과목마다 카드를 한 바퀴 다 돌기 전에는 반복하지 않습니다. 숫자 예제와 입법·기준 이야기가 함께 나옵니다.
6. 오늘의 기업: 그 업종이 돈 버는 구조, 연도별 숫자, 규모 진단, 업종 안 순위, 듀퐁 분해, 현금흐름 생애주기, 유효세율, 돈 감각 환산, 예산 감각 연습문제
7. 오늘의 퀴즈
8. 분야별 헤드라인(21개 분야, 누르면 펼쳐짐)과 공시 목록

토요일에는 복습 노트가 나옵니다. 한 주 동안 어느 분야 기사가 많았는지 날짜별로 보여주는 이슈 지도, 그 주의 이론·전공 수업, 사례, 퀴즈, 주말 과제가 들어 있습니다. 한 달에 한 번 업종별 규모 지도(대표 기업 100여 곳의 매출·이익·자산·직원·평균 연봉)가 갱신되고, 모든 카드는 [이론·제도 사전](reports/theories.md) 한 페이지에 교재처럼 모여 있습니다.

## 처음 설정(10분)

### 1. DART 인증키 발급(무료)

1. [opendart.fss.or.kr](https://opendart.fss.or.kr) 접속 후 상단 '인증키 신청/관리' → '인증키 신청'
2. 개인 용도로 신청하고 이메일 인증을 마치면 40자리 인증키가 나옵니다(하루 2만 건까지 무료, 이 프로그램은 하루 수백 건 정도 씁니다)

### 2. GitHub에 키 등록

저장소 Settings → Secrets and variables → Actions → New repository secret

| 이름 | 값 | 필수 |
|---|---|---|
| `DART_API_KEY` | 위에서 받은 인증키 | 필수 |
| `ANTHROPIC_API_KEY` | Claude API 키(공시·뉴스 사례에 'AI 해설'을 붙이고 싶을 때) | 선택 |

#### Claude API 키 만들기(선택)

1. [platform.claude.com](https://platform.claude.com)에 가입합니다. claude.ai 구독과는 별개 계정·별도 결제입니다.
2. 돈 넣기: Settings → Billing에서 크레딧을 미리 충전합니다(선불). 자동 충전(auto-reload)은 꺼 두는 편이 안전합니다. Claude Max·Ultra 구독 중이면 claude.ai의 Settings → Billing → API credits에서 콘솔 조직을 연결하면 매달 API 크레딧(Max 100달러)이 들어와 충전 없이 쓸 수 있습니다. Pro는 해당되지 않습니다.
3. 한도 걸기: Settings → Spend limits에서 월 한도(예: 10달러)를 정합니다. 한도에 닿으면 그달 남은 날은 해설만 빠지고 노트는 그대로 만들어집니다.
4. 키 만들기: Settings → API keys → Create key. 워크스페이스는 Default Workspace를 고르고, 만료는 Never(또는 1년 이상)로 둡니다. 워크스페이스를 고르지 않으면 요청이 거절되고, 만료를 30일처럼 짧게 잡으면 그날부터 해설이 조용히 빠집니다.
5. 키 값은 만들 때 한 번만 보여 주니 바로 복사해 위 표대로 `ANTHROPIC_API_KEY`로 등록합니다. 채팅이나 파일에는 붙여 넣지 않습니다.

### 3. 첫 실행

Actions 탭 → '매일 케이스 노트' → Run workflow. 2~3분 뒤 `reports/README.md`에 첫 노트 링크가 생깁니다. 그다음부터는 평일 아침 6시 30분(한국시간)에 저절로 만들어집니다.

처음 한 번은 작업(task)에 `scale`을 넣어 실행하면 업종별 규모 지도가 바로 만들어집니다. 특정 기업을 깊게 보고 싶으면 작업에 `company`, 회사 이름에 `삼성전자`처럼 넣으면 됩니다. 날짜 칸에 `2026-11-20`처럼 넣으면 그날 노트를 다시 만듭니다.

### 4. 휴대폰으로 보기(선택)

- 가장 쉬운 방법: GitHub 앱에서 `reports/README.md`를 열면 마크다운이 그대로 보기 좋게 표시됩니다.
- 웹페이지로 보기: Settings → Pages → Source를 'Deploy from a branch', 폴더를 `/docs`로 지정하면 `https://<아이디>.github.io/<저장소>/`에서 볼 수 있습니다(비공개 저장소는 GitHub 유료 플랜이 필요합니다).

## 휴대폰 앱(안드로이드)

노트를 휴대폰 앱으로 봅니다. 인터넷만 연결되면 앱이 GitHub에서 최신 노트를 바로 가져오고, 한 번 연 노트는 인터넷이 없어도 다시 볼 수 있습니다. `android/` 폴더가 바뀌면 GitHub Actions가 앱을 빌드해 Releases의 '케이스 노트 앱'에 `casenote.apk`로 올립니다.

### 1. 설치

1. 휴대폰 브라우저에서 https://github.com/wlstn0422/-/releases/download/app-latest/casenote.apk 를 엽니다. 저장소 화면에서 Releases → 케이스 노트 앱 → casenote.apk를 눌러도 됩니다.
2. 내려받은 파일을 열면 '출처를 알 수 없는 앱' 설치를 허용할지 묻습니다. 브라우저(크롬 등)에 허용하고 설치합니다. Play 프로텍트 경고가 나오면 '설치' 또는 '무시하고 설치'를 고릅니다.
3. 앱을 열면 바로 노트 목록이 나옵니다. 저장소가 공개라서 로그인이나 토큰이 필요 없습니다.

### 2. 저장소를 비공개로 되돌릴 경우(토큰)

저장소를 다시 비공개로 바꾸면 앱이 노트를 읽을 수 없게 되고, 앱에 토큰 안내 화면이 나옵니다. 이때는 본인 계정의 읽기 전용 토큰을 한 번 넣어야 합니다. 안내 화면의 '토큰 만들기' 버튼이 아래 화면으로 바로 연결됩니다. 휴대폰에서 만들기가 잘 안 되면 PC에서 만드는 편이 수월합니다.

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
2. Token name: casenote-app, Expiration: 길게(예: 1년)
3. Repository access: Only select repositories → 이 저장소 선택
4. Permissions → Repository permissions → Contents: Read-only
5. Generate token을 누르고 나온 토큰(github_pat_로 시작)을 복사해 앱의 설정 → GitHub 토큰에 붙여 넣고 저장

토큰은 휴대폰의 앱 전용 저장소에만 보관되고(백업 제외) 노트를 읽는 데만 씁니다. 저장소가 공개인 동안에는 설정의 토큰 칸을 비워 두면 됩니다.

### 3. 사용

- 첫 화면은 전체 노트 목록입니다. 노트 안의 링크(이론·제도 사전, 규모 지도)도 앱 안에서 열리고, DART 원문과 기사 링크는 휴대폰 브라우저로 열립니다.
- 화면을 아래로 당기면 새로고침, 오른쪽 위 메뉴에 전체 노트·새로고침·설정이 있습니다.
- 새 버전 앱은 같은 주소에서 내려받아 덮어 설치하면 됩니다.

## 내 컴퓨터에서 실행

파이썬 3.11 이상이 필요합니다.

```bash
pip install -r requirements.txt

# Windows(PowerShell): $env:DART_API_KEY="발급받은키"
export DART_API_KEY=발급받은키

python -m casenote doctor            # 키와 인터넷 연결 점검
python -m casenote daily             # 오늘 노트
python -m casenote company 삼성전자   # 기업 하나 깊게 보기(이름 또는 종목코드)
python -m casenote scale             # 업종별 규모 지도
python -m casenote weekly            # 지난 7일 복습
python -m casenote daily --date 2026-11-20   # 특정 날짜로 다시 만들기
```

결과는 `reports/`(마크다운)와 `docs/`(웹페이지)에 저장됩니다. 키 없이 실행하면 뉴스 사례, 이론 수업, 전공 수업, 퀴즈만 채워집니다.

## 매일 30분 공부 루틴(제안)

1. 오늘 한눈에(2분): 어제 무슨 일이 있었고 어느 분야 기사가 많았는지 훑기
2. 사례(10분): 사례마다 '사례 개요'와 '이론 적용'을 읽고, 요약을 내 말로 바꿔 말해 보기. 시간이 나면 '심화 학습'을 펼쳐 원문 항목과 회계·세무·법을 확인
3. 이론 수업(7분): 쉬운 설명을 읽고 '사례에 적용하는 순서'를 소리 내어 따라가 보기
4. 전공 수업(8분): 숫자 예제를 직접 계산해 보고, 세법·상법이면 입법 취지와 배경을 한 문장으로 말해 보기
5. 퀴즈(3분)

토요일에는 복습 노트의 이슈 지도로 한 주의 흐름을 보고, '주말 과제'처럼 사례 하나를 여섯 줄(무슨 일, 왜, 어떤 이론, 숫자, 회계·세법·상법, 내가 담당자라면)로 정리해 두면 면접과 실무 보고서에 그대로 쓸 수 있습니다.

## 비용

- DART API: 무료
- GitHub Actions: 공개 저장소는 무료, 비공개 저장소는 월 2,000분 무료 한도 안에서 충분합니다(한 번에 2~5분)
- 사례 해설과 이론 적용(사례 개요, 이론 적용, 용어 해설): 미리 써 둔 설명과 규칙으로 만들어 무료입니다.
- AI 해설(선택): Claude API 사용량만큼 과금됩니다. 평일 노트를 만들 때 한 번 호출해 공시 3건·뉴스 4건 해설을 한꺼번에 받습니다. 기본 설정(claude-opus-5-5, 노력 수준 medium)으로 한 번에 0.2~0.5달러, 평일만 돌면 한 달 5~11달러 정도로 추정합니다. 수동 실행도 한 번마다 과금됩니다. 실제 사용량은 Actions 실행 기록의 'AI 해설 토큰 사용' 줄과 콘솔 Usage 화면에서 확인합니다.
- 비용을 줄이려면 `config.yaml`의 `ai.model`을 `claude-sonnet-5-5`로 바꾸면 단가가 절반(입력 2달러, 출력 10달러/100만 토큰)이 됩니다. 기본값 `claude-opus-5-5`는 입력 4달러, 출력 20달러입니다. 키를 등록하지 않으면 해설 없이 무료로 돌아갑니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 노트에 'DART 사용 중단: 등록되지 않은 인증키' | Secrets의 `DART_API_KEY` 값에 공백이 섞였는지, 키가 맞는지 |
| '요청 제한 초과' | 하루 2만 건 한도. 같은 날 수동 실행을 여러 번 했는지 |
| 키를 넣었는데 'AI 해설'이 안 붙음 | Actions 실행 기록에서 'AI 해설' 줄 확인. 키 오류면 키 값·워크스페이스·만료를, 'credit balance is too low'면 충전을, 'usage limits'면 월 한도를 본다 |
| 금융지주·보험사 숫자가 빈칸 | DART 재무 API가 금융업 일부를 다루지 않습니다 |
| 뉴스가 0건 | 언론사 RSS 주소가 바뀌었을 수 있습니다. `data/news_sources.yaml`에서 주소를 고치거나 빼면 됩니다 |
| 아침에 노트가 늦게 생김 | GitHub 예약 실행은 몰리는 시간에 수십 분 늦어질 수 있습니다 |

## 참고

공시 숫자는 DART 원문 기준이고, 해설과 카드는 공부용 요약입니다. 법령, 회계기준, 예산 숫자는 2026년 11월 기준으로 정리했으니 실무 문서에 인용할 때는 국가법령정보센터, 한국회계기준원, 금융위원회·거래소, 기획예산처·재정경제부 발표에서 원문을 다시 확인하세요. 투자 판단용 자료가 아닙니다.
